## Findings (ranked)

### sec/auth/hardcoded-super-admin-backdoor
- severity: **blocker** · confidence: high
- evidence: `src/auth.ts:35-42` — hardcoded `admin@safesight.ai` / `password123` returns a SUPER_ADMIN session (pre-existing, but its blast radius grew: SUPER_ADMIN now flips agent settings via `PATCH /api/agent/settings`).
- impact: anyone who guesses the dev credentials gets SUPER_ADMIN on any deployment, including production.
- action: gate the branch behind `NODE_ENV !== 'production'` or a dedicated `ALLOW_DEV_LOGIN` flag, or remove it and seed a dev user in `db:seed`.

### tests/agent-session/daily-token-cap-untested
- severity: **blocker** · confidence: high
- evidence: `agent/session.ts:77` cap check has no exercising test; `agent/test/session.test.ts` covers only happy path and refusal; `agent/lib/usage.ts` has no test.
- impact: an off-by-one or a silently zeroed count lets the agent spend unlimited tokens per day.
- action: add `agent/test/usage.test.ts` (sum, malformed row ignored, local-day boundary) and a session test where a seeded `session.ended` row pushes usage over the cap → `SessionError{refundAttempt:true}` and no `client.run`.

### tests/agent-tools/escalate-untested
- severity: **blocker** · confidence: high
- evidence: `agent/tools/escalate.ts` has no test: VERIFIED/serious gate (32-34), `escalatePerSession` (23), paused short-circuit (21-22), no-`violationId` ops path (24-27).
- impact: the only gate before a real outbound Telegram send; a swapped operator ships spam or misses critical escalations undetected.
- action: add `agent/test/escalate.test.ts` covering the six cases listed by the reviewer.

### code/agent-direct/sigterm-to-stale-pid
- severity: high · confidence: medium
- evidence: `agent/direct/actions.ts:45-51` `process.kill(pid,'SIGTERM')` with pid from `public/snapshots/.heartbeat.json` (`agent/lib/capabilities.ts:19-24`), written by `ai-engine/yolo_inference.py:461-468` and never removed on exit; `agent/direct/health.ts:30-33` `pidAlive` accepts any live process of the user; `rateLimit` is the first `&&` operand at `actions.ts:47`.
- impact: after the engine stops, `engine.stalled` fires every sweep; once the OS recycles the pid, the agent SIGTERMs an unrelated process (next dev, bridge, editor), up to 3×/hour, silently.
- action: verify `/proc/<pid>/cmdline` contains `yolo_inference.py`, treat heartbeats older than a few minutes as "engine gone", move pid checks before `rateLimit`, and unlink the heartbeat in the engine on exit.

### tests/violations-route/status-uppercase-no-regression-test
- severity: high · confidence: high
- evidence: `src/app/api/violations/[id]/route.ts` PATCH now uppercases status; no test anywhere for the route.
- impact: regressing the fix silently writes lowercase statuses that every uppercase comparison misses.
- action: route-level test asserting PATCH `resolved` persists `RESOLVED` and responds lowercase.

### tests/agent-bridge/enqueue-dedup-untested
- severity: high · confidence: high
- evidence: `src/lib/agent-bridge.ts:6-12` reimplements lease-aware merge independently of `agent/lib/tasks.ts` `scheduleTask`; zero tests.
- impact: a divergence duplicates or drops `violation.review` / `health.probe` tasks silently.
- action: test that a leased task is not merged into and an unleased one is; or delegate to `scheduleTask`.

### code/agent-session/token-cap-silences-ask-panel
- severity: medium · confidence: high
- evidence: `agent/session.ts:77` throws before any event; `agent/main.ts:39-45` emits the error under `newSessionId()`; `src/components/agent/AskAgentBox.tsx:15,39-41` filters by the thread `sessionId` and needs `session.ended`.
- impact: after the cap, the ask panel shows "Agent đang trả lời…" for 90s then nothing.
- action: emit `skipped('đã chạm trần token trong ngày')` before throwing; use `task.sessionId` in the main-loop error emit.

### sec/deploy/bridge-published-to-all-interfaces
- severity: medium · confidence: medium
- evidence: `docker-compose.yml:28-29` publishes `4001:4001`; `ai-engine/yolo_bridge.js:66,73` binds all interfaces; `/detections` POST has no auth.
- impact: anyone on the network can inject fake detections (fabricated overlays, and via the engine path fabricated alerts).
- action: protect `/detections` with the existing `AI_ENGINE_SECRET` header (engine already holds it), or bind the published port to `127.0.0.1`.

### code/agent-bridge/poke-before-enqueue
- severity: low · confidence: high
- evidence: `src/app/api/cameras/[id]/route.ts:77-79` pokes before the enqueue promise resolves; compare `src/app/api/violations/route.ts:126-127`.
- impact: camera edit never triggers the immediate probe; waits for the 20s tick.
- action: chain `.then(() => pokeAgent(...))`.
